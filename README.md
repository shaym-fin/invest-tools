# השוואות תשואות ותכנון הלוואות חכמות

אתר אישי עם שני כלים:
- **השוואת תשואות** (`index.html`): קרנות פנסיה, קופות גמל וקרנות השתלמות, לפי נתוני רשות שוק ההון.
- **סימולטור הלוואות** (`leverage.html`).

הנתונים מתעדכנים אוטומטית ב־10 וב־20 בכל חודש.

## הקמה (פעם אחת, כ־15 דקות)

**1. פתיחת חשבון.** נכנסים ל־github.com ופותחים חשבון חינמי. שם המשתמש יופיע בכתובת האתר.

**2. יצירת מאגר.** לוחצים על ה־+ למעלה ובוחרים New repository. נותנים שם, למשל `returns`, ומסמנים Public. באתרים בחשבון חינמי המאגר חייב להיות ציבורי. לוחצים Create repository.

**3. העלאת הקבצים.** בעמוד המאגר לוחצים על **uploading an existing file**. מחלצים את קובץ ה־ZIP במחשב וגוררים את **כל התוכן** שלו לחלון: הקבצים והתיקיות, בלי התיקייה העוטפת. לוחצים Commit changes.
> התיקייה `.github` מוסתרת ב־Mac וב־Windows. אם היא לא עלתה, צרו אותה ידנית: Add file ← Create new file, ובשם הקובץ כתבו `.github/workflows/update-data.yml`, ואז הדביקו את תוכן הקובץ מה־ZIP.

**4. הפעלת האתר.** נכנסים ל־Settings ← Pages. תחת Source בוחרים Deploy from a branch, ואז `main` ו־`/ (root)`, ולוחצים Save. אחרי דקה־שתיים האתר יהיה זמין בכתובת:
`https://שם-המשתמש.github.io/returns/`

**5. משיכת הנתונים בפעם הראשונה.** נכנסים ללשונית **Actions**. אם מופיעה בקשה לאשר workflows, מאשרים. בוחרים **עדכון נתוני תשואות** ← **Run workflow**. אחרי כמה דקות, כשמופיע וי ירוק, מרעננים את האתר.

מעכשיו הנתונים מתעדכנים לבד.

## מי יכול לשנות מה
רק מי שמחובר לחשבון ה־GitHub שלך יכול לשנות את הקבצים. כל השאר רק צופים באתר.

## אם משיכת הנתונים נכשלה
ב־Actions לוחצים על ההרצה שנכשלה ← update ← משיכת נתונים, ומעתיקים את הודעת השגיאה. בדרך כלל אלה שתי סיבות:
- **השתנו שמות השדות במאגר הממשלתי.** ההודעה תפרט את השדות הקיימים, ומעדכנים את הרשימה `FIELDS` בקובץ `scripts/update_data.py`.
- **האתר הממשלתי חסם את הבקשה או לא היה זמין.** מריצים שוב מאוחר יותר.

## כתובת משלך (לא חובה)
ב־Settings ← Pages ← Custom domain מזינים דומיין שקניתם, למשל `www.my-site.co.il`, ומגדירים אצל רשם הדומיין רשומת CNAME ל־`שם-המשתמש.github.io`.

## הערות
- התשואות המוצגות הן תשואות ברוטו כפי שדווחו, לפני דמי ניהול.
- כדאי לבדוק בפעם הראשונה שיחידת המידה של עמודת הנכסים (מיליוני ₪) תואמת את המאגר.
